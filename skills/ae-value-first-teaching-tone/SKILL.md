# Value first, teaching tone

Read `brand/profile.md`. If it is missing or a section this skill needs (`## Voice and tone`, `## Audience`, `## Rules`, `## Claims policy`) is empty, stop and run `ae-setup-interview` for that section (ask the user, with options), do not guess.

## The principle

People do not want to feel sold to, and when they feel sold to, they leave. The persuasion in a good script is the facts: a real number, a real result, a real screen. So every point teaches. It tells the viewer what they get, then what it is called, then how little effort it takes. The offer or call to action can still be clear and warm, but it comes as a helpful offer, once, at the end.

## The order for every point: value, name, ease

Every point (a tool, method, feature, step, list item) is written in this order:

1. Value: the outcome the viewer wants, in the viewer's words. Openers: "If you want X", "So if you need Y", "When you want Z".
2. Name: only then, the name. "then use [name]", "then there is [name]", "then you have got to try [name]".
3. Ease: how little the viewer has to do. "you just tell it ..., and it does the rest", "you paste it in and it fills the rest", "it takes about a minute".

Never open a point with the name ("First is [name]", "Second is [name]", "[Name] is an insane tool that"). A name with no stated value is noise.

Before and after (placeholder content, invented tool described by what it does):

| | Line |
| --- | --- |
| Before (name first) | "First is a recipe scaler, you type the loaf size and it adjusts the amounts." |
| After | "So if you want to double a recipe without doing the math, then use a free recipe scaler, where you just type the size you want and it fixes every amount for you." |

| Before | After |
| --- | --- |
| "[Name] is a revolutionary platform for planning." | "If you want a week of bakes planned in one sitting, then a planning sheet like this one does it, you just list what you want to bake and it lays out the timing." |
| "This secret method will change everything." | "If your loaves keep coming out dense, then try this one change, you let the dough rest until a wet finger dent springs back slowly." |

For a single product, use capability before brand: the problem the viewer has, the capability they want ("Imagine having a helper that scales any recipe in a second"), what makes it distinct, then the name, then at most 3 capabilities the product page documents.

## Spoken details that make it feel taught, not sold

- Point at the thing and name the kind of thing it is: "this recipe scaler", "this open source repo", "these three spreadsheets". A pointing word plus a plain category noun lets a viewer outside the field follow.
- Signposts only in list scripts: So, And, Then, Now, and "And lastly" on the final item. Story scripts use causal transitions.
- Complete clauses: "where you just type the size", not a dangling "a tool, simple to use".
- End each point on the viewer: "and it does the rest for you", "so your first loaf is not a guess".
- Explain an unknown name aloud as a friendly aside: "which, if you do not know it, is a big free library of recipes".
- Soft advice, varied: "then you should use this", "then try this", "you can use these". Not the same verb four times, and no orders ("you must", "you need to do this now").
- Every "if" gets its "then".
- Use "or" for alternatives in a list of jobs.

## Friend tone (ask the user which voice they want)

Interview options (also stored in `## Voice and tone`): (a) a calm teacher, (b) a smart friend with light humour, (c) a dry expert, (d) an energetic coach. This skill defaults to (b) when the profile is silent, and says so. Friend tone means:

- Educational and valuable, with light humour in the story and the commentary, like a smart friend telling you about it over coffee. The practical advice stays plain and clear.
- A friend's first reaction can open a line ("Well, that was not on the label."), as long as the fact after it is true.
- Respect for every person and company. When a leader leaves a company, say plainly that the company still runs. Never joke about someone's private life, family, health or about people involved in a scandal. Name nobody who does not need to be named.
- A comparison person or company appears in one place only, as a short cameo, never as the point of the video.
- A new or interim leader or newly named thing gets the real, sourced reason in one light line.

Humour rules (hard):
1. The humour sits in the reaction and the commentary, never in the numbers, steps, names or claims.
2. A joke is never the only way the viewer learns a fact.
3. No humour at the expense of the viewer's failure ("you are doing it wrong, idiot"). Self deprecation about the user's own past is fine only if true.
4. No swear words unless the user asks for them (their own words stay as they typed them).
5. A funny line must still be true. A made up anecdote for the laugh is an invented fact.
6. At most one joke per beat, at most 3 in a short.

## Banned and watched hype words

Full list with swaps is in `references/hype-list-and-swaps.md`. Summary: do not use pressure and superlative words in the points (insane, crazy, game changer, mind blowing, unbelievable, secret, revolutionary, must have, you need this now, nobody is talking about this, magic, explosive). The hook may be bold and true; a true bold hook does not need these words. Avoid "free" unless the free tier limits are checked and stated. Avoid "guaranteed", "100 percent", "always", "never" about outcomes. Avoid "best" with no named comparison. Avoid fake scarcity ("only today") and fake disbelief ("you will not believe").

Allowed in an opening stack (when true and paid off): "here is the part the coverage skipped", "most of the coverage is about [A]". Not allowed anywhere: invented prevalence ("everyone is doing this", "90 percent of people") without a source.

## Be honest about the human part

Leverage is real only when you say what the viewer still does. "Without any hard work" becomes "without the boring part" or "you only decide". "Fully automatic" becomes "it drafts, you check". "Instant" becomes the measured time. State one real limit in a beat labelled CATCH: what it cannot do, what it costs, what takes setup. A script with no limit sounds like an advertisement.

## Teach, then offer

The persuasion is the teaching. The call to action stays a simple, helpful offer, said once at the end (`ae-call-to-action-writing`). Do not pitch in the middle. Do not stack several offers.

## Process for any draft

1. List every point and mark: has value first? name second? ease third?
2. Rewrite each point that fails, using the order above.
3. Scan for hype words with `references/hype-list-and-swaps.md`; replace each with the fact behind it ("a game changer" becomes what changed, by how much, measured how).
4. Check each claim of ease against reality: if setup takes 20 minutes, say "simple to use after a short setup".
5. Check tone against the profile voice; keep humour inside the humour rules.
6. Add one honest limit if none exists.
7. Show the user a table: old, new, reason.

## Worked example (placeholder)

Draft (sold):
"Check out this amazing tool, it is an absolute game changer for bakers, and you need this now."

Taught:
"So if you want a week of bakes laid out so nothing goes in the oven at the wrong time, then use a free planning sheet like this one, where you just list what you want to bake and it works out the timing. It will not taste the bread for you, so you still decide when the loaf is done."

Changes: value first (a week of bakes that do not clash), name (a planning sheet) second, ease (just list what you want) third; removed "amazing", "absolute game changer", "you need this now"; added an honest limit.

A friend tone variant of the hook: "Well, that is not what the bag said." followed by the real fact. Only if the fact is real.

## Failure modes

| Failure | Fix |
| --- | --- |
| Name opens the point | Move the value first |
| A hype word hides a missing fact | Find the fact; use it; delete the word |
| "Free" without the limits checked | Check; say "free up to [limit]" |
| Humour inside a claim | Move it out |
| No limit stated | Add one honest limit |
| Sounds like a strict teacher | Allow a friend reaction and light humour if the voice allows |
| Pitch in the middle | Move the offer to the end, once |
| Rewriting the user's own words | Suggest in a table; never overwrite (`ae-script-first-workflow`) |

## Checklist

- [ ] Every point: value, then name, then ease.
- [ ] No banned hype words; each swapped for the underlying fact.
- [ ] Tone matches the profile; humour only in reaction and commentary.
- [ ] One honest limit present.
- [ ] Respect rule applied (no private life jokes, one cameo, nobody named needlessly).
- [ ] "Free", "best", "fast" claims have ledger rows.
- [ ] Offer appears once, at the end.
