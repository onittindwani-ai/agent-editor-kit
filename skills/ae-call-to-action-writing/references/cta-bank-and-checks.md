# CTA bank and checks (placeholder subjects)

Fill brackets from the profile and the real resource. Every number must exist.

## Resource by comment keyword (value first)
- "And if you want [the thing] for yourself, then just comment the word [KEYWORD] down below, and I will send it over to you directly."
- "So if you want the [N] [parts] I use for this, then comment [KEYWORD], and I will send them to you."
- "If you want the checklist that covers all of this, comment [KEYWORD] below and it is yours."

## Link in the description
- "And if you want the guide, then you can find the link in the description."
- "The link to the [resource name] is in the pinned comment, and it is free up to [limit]." (only with the limit checked)

## Platform without direct messages (two parts, still one ask)
- "You can find the link in the description and the pinned comment. So tell me in the comments, which [thing] would you try first?"

## Series follow
- "That was part 1 of [N], where the next part covers [specific topic]. Follow so you see it." (only if part 2 exists or is scheduled with the user)

## Long form end
- "If you want the [resource], the link is in the description. And if you liked this, the next video shows [specific thing]." (one resource link, one next video, no third ask)

## Takeaway lines (new angle), then action
- "Most people ask which tool to buy. The better question is which job you do twice a week, so start there."
- "The oven is rarely the problem. Check the rest time first, and the guide shows the three checks."

## Pre post checks
1. Count the promised parts in the folder. Record the count and date.
2. Open every file; follow every step as a viewer would.
3. Open every link signed out in a private window.
4. Confirm the keyword spelling in audio, captions, description and the delivery message are identical.
5. Confirm no other automation uses the keyword.
6. Confirm the disclosure line if the link is affiliate, sponsored or paid.
7. Read the ending once more: one action, value first, nothing promised that does not exist.

## Things never to promise
Guaranteed results, income, medical, legal or safety outcomes, a free audit or call the user will not give, a count of items that does not exist, anything the platform does not allow.
