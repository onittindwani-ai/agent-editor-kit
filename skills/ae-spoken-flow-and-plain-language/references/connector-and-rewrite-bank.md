# Connector bank, plain word swaps and more rewrites

## Plain word swaps

| Instead of | Say |
| --- | --- |
| utilise, leverage | use |
| demonstrate | show |
| commence, initiate | start |
| approximately | about |
| subsequently | then, after that |
| in order to | to |
| a large number of | a lot of, many |
| facilitate | help, make easier |
| prior to | before |
| individuals | people |
| purchase | buy |
| sufficient | enough |
| optimise | improve, tune |
| functionality | what it can do |
| methodology | method, way |
| ascertain | find out |

## Spoken openers for a point (list scripts only)

Use a different opener each time: "So if you want ...", "And if you need ...", "Then there is ...", "Now, when you want ...", "And lastly, ...". Story scripts use causal links instead: "which is why", "and that is where", "so what happened next was".

## Bridges that keep a viewer moving

| Situation | Bridge |
| --- | --- |
| After a surprising fact | "Here is why that happens." |
| After a definition | "So what does that mean for you?" |
| Before the catch | "There is one thing to watch." then say what, in the same breath |
| Before the payoff | "And this is the part that fixes it." |
| Between two list items | "That covers [A]. If you want [B], ..." |

Answer an objection right after the line that raises it, in the same flow. Do not announce it with "you might be thinking" or "here is the answer to that"; those phrases sound like homework.

## More before and after pairs (placeholder content)

1. Article voice.
Before: "Fermentation duration is dependent on ambient temperature."
After: "The warmer your kitchen is, the faster the dough rises, so a warm day means you check it sooner."

2. Fragment appositive.
Before: "Our guide, twelve pages of baking schedules."
After: "It is a guide with twelve pages of baking schedules, where each one is for a different kind of loaf."

3. Unexplained term.
Before: "Check the autolyse before mixing."
After: "Let the flour and water sit together for half an hour first, which bakers call an autolyse, because it makes the dough easier to shape."

4. Stacked abstractions.
Before: "Our solution optimises throughput of order fulfilment."
After: "We pack the orders faster, so customers get their bread the same morning."

5. Missing object.
Before: "Then click one and it opens."
After: "Then click the first schedule in the list, and it opens in a new tab."

6. Same length lines.
Before: "It is simple. It is fast. It is free. It is easy."
After: "It is free, it takes about a minute, and you do not need to set anything up."

## Teleprompter file example

```
If your loaf comes out dense, it is probably not your oven.

So if you bake at home and keep blaming the heat, the real problem usually happens hours before the loaf goes in.

It is called underproofing (pronounced under-PROOF-ing), which just means the dough did not rest long enough.
```

No headings, no times, no notes. Pronunciation hints are bracketed and are not spoken.
