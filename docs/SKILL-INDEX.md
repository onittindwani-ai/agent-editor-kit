# Skill index

42 skills. Each is a folder in `skills/` with a `SKILL.md`; many also have a `references/` folder with templates and tables.

## Setup and operation

| Skill | What it does and when it is used |
| --- | --- |
| [`ae-start-here`](../skills/ae-start-here/SKILL.md) | The front door of the Agent Editor Kit. Use it first on every new session or when the user says "get started", "set up the editor", "what can this kit do", "help me edit a video", "where do I begin" or names any kit task without saying which skill. It checks that a brand profile exists, refuses to continue any other kit task until `brand/profile.md` exists, runs the setup interview when it does not, and routes the user to the right skill. |
| [`ae-setup-interview`](../skills/ae-setup-interview/SKILL.md) | The long onboarding interview that creates `brand/profile.md` and `brand/theme.json`. Use when the user says "set up", "start", "onboard me", "my brand", "change my colours", "update my profile", or when any skill finds the profile missing or a section empty. It asks about business, audience, offer and call to action, voice, script style, visual theme, captions, sound, platforms, rules and claims in 12 rounds with 3 to 5 options and an example for each, confirms everything, then writes the files. |
| [`ae-profile-schema`](../skills/ae-profile-schema/SKILL.md) | The exact file formats of `brand/profile.md` and `brand/theme.json`, with every key, a validation checklist and a validator, plus how to read one value and how to update a single section safely. Use when the user asks "what does my profile look like", when a skill needs to know where a value lives, when the profile looks broken, or before writing or editing either file. |
| [`ae-install-and-run`](../skills/ae-install-and-run/SKILL.md) | Installs and verifies everything the Agent Editor needs (Python 3, ffmpeg and ffprobe, a whisper command line tool that writes word timestamps, Pillow, optional Remotion), ingests a video, starts the editor server on 127.0.0.1:8780, runs health checks and fixes common errors. Use when the user says "install", "set it up", "run the editor", "start the server", "ingest my video", "port in use", "it does not start", "no transcript", or before any multi agent edit. |
| [`ae-run-multi-agent-edit`](../skills/ae-run-multi-agent-edit/SKILL.md) | The conductor for a multi agent edit in the Agent Editor. Plans time windows, launches 7 or more Claude Code subagents (cutters, captioners, fx, graphics, a reviewer) with the agent brief and a role skill, watches progress, handles refusals and re runs, runs the review and fix rounds, and renders only after the user's explicit go. Use when the user says "edit this video with all the agents", "run the edit", "start the agents", "cut and caption this", "use 7 agents", or after ingest is done. |
| [`ae-agent-cutter`](../skills/ae-agent-cutter/SKILL.md) | Role skill for a cutter agent in the Agent Editor. Explains the exact rules the server enforces on cuts, how to compute cut points from word times, one cut per phrase, gap midpoints, words that touch, minimum length, restarts and fillers, and how to read a NO. Use when you are launched as a cutter (role "cutter"), when the user says "cut my window", "remove the pauses and mistakes", or when a conductor briefs you with a time window. |
| [`ae-agent-captioner`](../skills/ae-agent-captioner/SKILL.md) | Role skill for a captioner agent in the Agent Editor. Explains the exact rules the server enforces on captions (1 to 3 words, 22 characters, 0.2 to 3 s, transcript words only, no overlaps), how to group words, where to split, how to time a caption, how to spell, and how to check coverage. Use when you are launched as a captioner (role "captioner"), or when the user says "caption my window", "add captions", "make captions for the kept speech". |
