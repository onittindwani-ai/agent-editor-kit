# Agent Editor Kit: instructions for coding agents

This repository holds `agent-editor/` (a shared timeline editor with an HTTP API that many agents can drive at once)
and 42 skills in `skills/<name>/SKILL.md`.

Before doing anything else for the user:

1. If `brand/profile.md` or `brand/theme.json` is missing, read `skills/ae-start-here/SKILL.md`, then
   `skills/ae-setup-interview/SKILL.md`, and run the interview. Ask many questions in rounds, with options.
2. Only after the profile exists, write scripts, plan graphics, edit or render.
3. Read the matching `skills/<name>/SKILL.md` in full before each task. Follow the gates inside it.

Never invent facts, never export or publish without the user's explicit go, one heavy job at a time, look at frames
before claiming an edit is done. Details are in `CLAUDE.md`.
